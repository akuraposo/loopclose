How the loop closes

  1. Agent asks to deploy. Gate is closed until proof arrives.
  2. Kane CLI drives this page in a real browser and asserts the flow. Its verdict comes back as --agent NDJSON.
  3. The gate reads the verdict from ?verdict=passed plus an evidence link. No proof, no deploy.
  4. On failure the agent applies a fix and calls Kane again. That is the closed loop — the same thing the judges score.
